# Fizz Buzz

**Difficulty:** Easy

**LeetCode:** https://leetcode.com/problems/fizz-buzz/

## Approach

Iterate from 1 to n. If a number is divisible by both 3 and 5, output "FizzBuzz". If it is divisible only by 3, output "Fizz". If it is divisible only by 5, output "Buzz". Otherwise, output the number itself.

## Time Complexity

O(n)

## Space Complexity

O(n)
